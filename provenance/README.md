# Provenance

The `*_meta.json` files are generated by `code/s0_fetch.py` and record the
OpenML identifier, sample counts, split sizes, encoded dimensions, feature
groups, and class rate used in the study.

`input_artifact_sha256.json` binds the frozen inputs used by `reproduce.py`.
Derived summaries and figures are intentionally omitted from that hash set so
they can be regenerated and compared.
